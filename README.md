# Showcase Designer

Интерактивный прототип настройки витрины услуг на React и TravelLine Reactor.

**Прототип:** https://glazest-t.github.io/showcase-designer/

Возможности: создание и редактирование разделов, выбор иллюстрации или варианта «Без картинки», привязка услуг с поиском и фильтрацией, меню удаления, подсказки, переключатели видимости и просмотр деталей услуг.

Данные демонстрационные. Изменения хранятся в памяти вкладки и сбрасываются при перезагрузке.

## Локальный запуск

Для установки `@reactor/*` требуется доступ к частному npm-реестру Reactor. Настройте его в локальном `.npmrc` (не добавляйте этот файл в Git).

```sh
npm install --cache ./.npm-cache
npm run dev -- --port 4173
```

## Обновление публикации

```sh
VITE_BASE_PATH=/showcase-designer/ npm run build
rm -rf docs
cp -R dist/client docs
touch docs/.nojekyll
```

Закоммитьте исходники и `docs`, затем отправьте изменения в ветку `main`. GitHub Pages публикует каталог `docs`; доступ к частному реестру на стороне GitHub не требуется.
